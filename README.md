# TestForge MCP Server 🧪🛡️⚡

Universal Autonomous Full-Stack QA, E2E Playwright, Vitest & Chaos Fuzzing Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_full_stack_qa_and_test_suite_architect`):** Ingests code or architecture specs and outputs an exhaustive, production-ready QA test suite (Unit tests + Playwright E2E + Fuzzing + Mock fixtures + CI/CD pipeline).
- 🧪 **Autonomous Unit & Integration Test Suites (`generate_unit_test_suite`):** Generates robust Vitest/Jest/Pytest test suites with zero-dependency mocks, boundary checks, and snapshot assertions.
- 🎭 **Enterprise Playwright E2E Browser Specs (`generate_playwright_e2e_suite`):** Generates multi-browser and mobile viewport automated test journeys with visual regression assertions.
- 💥 **Chaos & Fuzzing Threat Matrix (`edge_case_and_fuzz_tester`):** Generates hostile payloads (SQLi, XSS, Unicode edge cases, integer overflows, race conditions) to bulletproof APIs.
- 📦 **Synthetic Mock & Fixture Factory (`mock_data_and_fixture_factory`):** Produces typed mock datasets, Faker seeds, and MSW network handlers.
